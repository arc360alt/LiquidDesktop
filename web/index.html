A Liquid Glass desktop for Linux

Dock, menu bar, Control Center, Spotlight, widgets and built-in apps, with real windows for your Linux apps. Try the live demo below; nothing to install.

Runs entirely in your browser
Live demo: the same web UI the desktop uses. Files, Terminal and system controls are simulated here.

Liquid Glass everywhere

Real blur, refraction and depth on the Dock, menu bar, menus and widgets.

Your Linux apps, framed

A real X11 window manager puts every app in a macOS-style window.

App Store

Flathub and Arch Linux packages in one place, with updates.

Built-in apps

Files, Terminal, Browser, Notes, Calendar, Weather, Activity Monitor, Settings and more.

Install it

One command picks the right method for your distro (Arch uses a proper package). Then choose “LiquidDesktop” on your login screen.

curl -fsSL https://raw.githubusercontent.com/arc360alt/LiquidDesktop/main/install.sh | sh
Or try it on your computer without logging out: liquid-desktop opens it in a window.
